# Security policy

Owner: Maintainers
Last reviewed: 2026-08-21

Report suspected credential exposure or a vulnerability privately through GitHub Security Advisories. Do not open a public issue containing secrets, user data, or reproduction details that enable abuse.

Supported code is the current `main` branch until versioned releases begin. Maintainers will acknowledge a report within three business days, coordinate containment and credential rotation first, then publish remediation information after affected users can update.

Never send a Discord token for diagnosis. Use the redacted diagnostics view and [startup runbook](docs/runbooks/startup-failure.md).

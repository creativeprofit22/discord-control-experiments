## Method

- Host: `windows/amd64`; CPU: `AMD64`; source: `4d25fa65f0483ba9342d66851b4eddc80da1c0a1`.
- Cold and MCP startup: 50 fresh processes each. REST: 100 warmups plus 1000 measured keep-alive requests across 5 runs. Clean builds: 5.
- Peak memory is externally sampled resident working set. TypeScript deployable size includes compiled output, production dependencies, and the pinned portable Node runtime.
- Score weights: memory 25%, artifact 20%, cold 20%, MCP 15%, REST 10%, build 10%; each value is normalized to the best eligible candidate. Within 5%, Go wins the single-binary tie-break.

## Limitations

- Single Windows host; background load, filesystem cache, antivirus, and power policy can affect samples.
- Loopback REST isolates client overhead and JSON decoding; it does not model Discord network latency or response-driven rate limiting.
- Artifact size is uncompressed deployment bytes and is not an installer or transfer-size comparison.
